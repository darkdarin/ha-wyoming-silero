# Wyoming Silero

A [Wyoming](https://github.com/OHF-Voice/wyoming) text-to-speech server for Home Assistant on the Russian
[Silero](https://github.com/snakers4/silero-models) model `v5_6_ru` (voices `aidar`, `baya`, `kseniya`, `xenia`,
`eugene`). It runs locally on the CPU (Raspberry Pi 5 and amd64), with no cloud.

> Work in progress: not released yet.
